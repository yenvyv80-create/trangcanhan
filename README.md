Bạn là một chuyên gia UI/UX Designer và Frontend Developer với kinh nghiệm thiết kế portfolio hiện đại.

Nhiệm vụ của bạn là thiết kế và viết code hoàn chỉnh cho một website portfolio cá nhân bằng HTML + CSS (có thể thêm JavaScript nếu cần cho tương tác), đảm bảo giao diện hiện đại, tối giản, chuẩn UI/UX.

Yêu cầu chi tiết:

1. Thông tin cá nhân:
- Tên: Võ Ngọc Yến Vy
- Nghề nghiệp: Sinh viên
- Trường: Đại học Gia Định
- Ngành học: Đồ họa Kỹ thuật số
- Khoa: Công Nghệ Thông Tin

2. Cấu trúc website gồm các section:
- Header (logo + menu điều hướng + nút chuyển theme)
- Hero (ảnh đại diện + giới thiệu ngắn + CTA button)
- About (giới thiệu bản thân)
- Skills (kỹ năng thiết kế / công cụ như Photoshop, Illustrator,...)
- Projects (hiển thị 2–3 project dạng card hiện đại)
- Contact (email / mạng xã hội)
- Footer

3. Thiết kế UI/UX:
- Phong cách hiện đại, tối giản (minimal + clean)
- Sử dụng layout grid hoặc flexbox
- Có khoảng trắng hợp lý (white space)
- Typography rõ ràng, dễ đọc
- Có hover effect mượt

4. Theme:
- Có 2 chế độ: Dark mode và Light mode
- Có nút toggle ở header để chuyển theme
- Sử dụng CSS variables để quản lý màu
- Transition mượt khi đổi theme

5. Yêu cầu code:
- Viết toàn bộ trong 1 file HTML (có thể tách CSS nếu cần)
- Code sạch, dễ đọc, có comment
- Responsive (hiển thị tốt trên mobile + desktop)
- Không dùng framework (chỉ HTML, CSS, JS thuần)

6. Trải nghiệm người dùng:
- Animation nhẹ (fade in, hover)
- Button rõ ràng
- Navigation mượt (scroll)

7. Output:
- Trả về code hoàn chỉnh
- Có thể chạy trực tiếp
- Không giải thích dài dòng, tập trung vào code chất lượng cao
